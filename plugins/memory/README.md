# 记忆（memory）

Cc 的长期记忆：一张**会变模糊的图**。

AI 记住踩过的坑、有理由的决定、项目约定、环境事实和术语；用到的会变亮变大，长期不用会淡下去，被推翻的变灰，你随时能钉住、作废或删掉。**不往上下文里塞任何常驻内容** —— 记忆只在两种时候出现：AI 主动查，或者它正要读某个文件/跑某条命令时靠过来。

## 界面

左栏「插件」下面点「记忆」：

- **节点大小 = 有效强度**，透明度 = 强度，颜色 = 类型，灰实心点 = 作废，虚线圈 = 隔离区，金色环 = 钉住。
- **边**：共享标签 / 指向同一文件或服务 / 取代关系（虚线）/ 同一次任务产生。
- **搜索框**：打字就把命中的节点高亮、其余压暗让开（不切页面）。
- **点节点** → 右侧详情：**正文可直接改**（类型 / 重要度 / 标签 +「保存修改」），以及钉住、有用 / 没用、作废、恢复、删除、来源对话。
- **回收站**（工具条右侧按钮）：删掉的东西先进这里躺 30 天，可「恢复」或「彻底删除」，到期自动清掉。
- **隔离区**：自动记下但还没被用上的记忆待在这里，可「升级」为正式记忆或直接删除（也可以全部升级）。
- **＋ 新建**：手写一条（类型 / 重要度 / 范围 / 原话 / 标签），不依赖 AI。
- **批量**：进入批量模式后点节点多选（或「全选当前筛选」），一起作废 / 删除 / 钉住。
- **整理**：合并近重复 + 把指向已删除文件的记忆作废（每天最多自动跑一次，也能手动点）。
- **当前项目 / 全部项目**、**含淡出**、**导出**。

切到记忆视图后左栏会收起（和切「终端 / Git」一样），回来点顶栏的「对话」。

## AI 侧

| 工具 / 命令             | 作用                                         |
| ----------------------- | -------------------------------------------- |
| `memory_search`         | 按关键词/文件/命令/报错查记忆                |
| `memory_write`          | 记一条（类型 + 一句话 + 可选原话）           |
| `memory_update`         | 改一条（命令变了、约定改了用它，别另写一条） |
| `memory_forget`         | 作废（默认，可恢复）或删除                   |
| `/remember [类型] 内容` | 你手写一条；类型可省（按词面猜）             |
| `/recall 关键词`        | 你查记忆（结果只给你看）                     |
| `/forget <id> [删除]`   | 作废；加「删除」= 彻底删 + 不再自动记回      |

## 怎么变旧

不按类型设过期时间：

- **强度**：初始 1。被检索返回 +0.2；同一轮里它绑定的文件/命令真被工具用到 +1；你点「有用」+1 /「没用」−1；否认立即变灰。
- **衰减**：半衰期只看重要度（5 ≈ 90 天、3 ≈ 30 天、1 ≈ 7 天），被用到就重新计时。**没有任何到点删除**。
- **换代**：新记忆和旧的矛盾时，写入那一刻判定谁赢，旧的变灰并连一条边 ——「偏好变了」走这条路，不走时间。
- **作废 ≠ 删除**：作废默认不参与检索，可一键恢复；删除进 30 天回收站，并留指纹防止自动抽取又记回来（你手写命令可以加回来）。

## 数据在哪

```
<dataDir>/memory/                 ← 与 plugins/ 平级，插件怎么覆盖/重装/卸载都碰不到
  memories.jsonl                  主库（一行一条）
  blacklist.json                  删过的指纹（别再自动记回来）
  audit.jsonl                     谁在什么情况下写了什么
  backups/                        快照：启动时当天一份 + 每次物理删除前一份，保留最近 5 份
```

`<dataDir>` 默认是 `~/.pi-web`，即 `~/.pi-web/memory/`。界面上有「导出」按钮，导出整库 JSON。

- **从老位置迁移**：老版本放在 `<dataDir>/plugins/memory/data/`。插件启动时会把它**复制**过来（不移动、不删）；新位置已有数据时以新位置为准，不会把旧的灌回来。迁移成功会留一条日志，旧目录确认无误后可自行删除。
- **误删恢复**：从 `backups/` 里挑一份，改名为 `memories.jsonl` 覆盖主库即可（先停服务）。
- **卸载插件**：记忆**不会**跟着消失（这是数据搬出插件目录的直接收益）。要彻底清空，删掉 `<dataDir>/memory/` 整个目录。
- **不装插件**：文件仍在，是纯 JSONL，任何编辑器都能读；`eval/run.mjs` 也能直接拿它跑题库。

## 关掉会怎样

设置 → 界面插件 → 关掉「记忆」：插件**真正停下**（AI 工具、HTTP 路由、订阅、逐条提醒全部撤回），按钮消失；再打开即恢复，**记忆一条不少**（数据在磁盘上，开关不碰它）。

## 题库（效果红线）

```bash
node plugins/memory/eval/run.mjs            # 读 ~/.pi-web 的库与本目录题库
node plugins/memory/eval/run.mjs --json
```

`eval/queries.json` 里每条写 `{ q, expect: [id...], bad: [id...] }`：`expect` 是应该返回的条目 id，`bad` 是已知错误/过期、出现即算有害的 id。**有害召回率超过 5% 就停止加功能**，先修检索与失效判断。
